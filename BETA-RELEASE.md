# EasyWin 1.3.0-beta.1

Экспериментальная бета для тестирования. Полный цикл с настоящей перезагрузкой, установкой и первым запуском ещё не проверен. Сначала используйте UEFI-виртуальную машину с одноразовыми дисками. Для основного ПК обязательны внешняя резервная копия и независимый носитель восстановления.

- Отдельный сохраняемый StagingDisk; целевой диск не нужно сжимать в двухдисковом режиме.
- Раздельный выбор целевого диска, хранилища и дополнительного диска для очистки.
- Повторная проверка идентичности, manifest и хэшей до разрушительных команд.
- Независимые ошибки Preflight, BCD ramdiskoptions и rollback, schema v2.
- Сохранён защищённый однодисковый режим.
- Release build и 67/67 автоматических тестов пройдены.

Распакуйте EasyWin-1.3.0-beta.1-win-x64.zip целиком. В папке EasyWin запускайте EasyWin.Desktop.exe. Это не обновляет старую установленную копию автоматически. Release запускается в реальном режиме; для симуляции используйте аргумент --dry-run.

Пакет не содержит ISO Windows, ADK/WinPE Microsoft, установщиков сторонних программ, экспортированных драйверов, персональных manifest/logs, ключей или лицензии Windows. Для реального запуска нужны официальные компоненты и доверенные payloads с совпадающими хэшами; отсутствующие пакеты блокируют установку.
