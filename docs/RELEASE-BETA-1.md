# EasyWin Beta 1 (1.4.0-beta.1)

Экспериментальная версия для тестирования в UEFI-виртуальной машине с одноразовыми дисками. Не используйте для переустановки рабочего ПК: реальный полный цикл установки ещё не проверен.

## Скачать и запустить

Скачайте `EasyWin-Beta-1-win-x64.zip`, распакуйте полностью и запустите `EasyWin.Desktop.exe`. Для безопасной симуляции запускайте с аргументом `--dry-run`. Не удаляйте вложенные папки WinPE/PostInstall и config.

Windows ISO, ADK/WinPE, сторонние установщики, экспортированные драйверы, лицензия Windows и личные данные в архив не входят. Они не скачиваются автоматически этим релизом. Активация возможна только при наличии действующей лицензии.

## Изменения

- Проверка BitLocker по числовому статусу, точный выбор staging-тома и повторная проверка идентификаторов.
- Использование подходящего нераспределённого пространства перед уменьшением раздела.
- Резервный SYSTEM-запуск PostInstall, блокировка одновременных запусков, контрольные точки программ.
- Запрет повторного запуска очистки дисков после начала разрушительного этапа.
- Проверка файлов зависимостей, выбор папки WinPE, копирование диагностики и сохранение журналов.
